# StudySync – Education Landing Page 🎓

StudySync is a modern, responsive education platform landing page built using **HTML5** and **CSS3**.  
The project focuses on clean UI design, structured layout, and beginner-friendly frontend practices.

---

## 🚀 Features

- Clean and modern landing page UI
- Responsive navigation bar with hamburger menu
- Hero section with call-to-action buttons
- Trusted companies showcase
- Feature grid with detailed cards
- Testimonials section
- Newsletter subscription section
- Well-structured footer with multiple columns

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- No JavaScript (Pure HTML & CSS)

---

## 🎯 Purpose of the Project

This project was created to:
- Practice semantic HTML
- Improve CSS layout skills (Flexbox & Grid)
- Build a real-world landing page
- Strengthen frontend fundamentals
